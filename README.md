# 3D Endless Runner Game

A 3D endless running game built with Unity and C#. The player runs forward automatically, dodging obstacles and collecting points to achieve the highest score.

## ✨ Features
- Endless procedural level generation
- Score tracking and high score system
- player controls (jump, slide, lane switching)
- Main menu,and game over UI
- hover board appear
- flying feature
- get shield during run and pass through obstacles


## 🛠️ Tech Stack
- **Engine:** Unity [6000.5.9f1]
- **Language:** C#
- **Version Control:** Git & Git LFS

## 🕹️ Controls
- **Space button :** Jump
- **S :** Slide
- **A / D :** Switch Lanes
  
## 🧠 What I Learned
- Implementing object pooling for obstacles to optimize performance.
- Designing a scalable game loop and state management.
- Managing version control for large Unity projects using Git LFS.
